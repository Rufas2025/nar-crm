# 00_Indice_Mestre_da_Base_de_Conhecimento

Pasta atual: `00_Governanca_e_Arquitetura`

## Propósito

Este documento é o mapa da base de conhecimento do ecossistema NAR ECO. Ele registra quais
pastas existem, quem é o dono de cada uma e qual convenção de nomes se aplica. Não contém
conteúdo de marca, regra comercial nem instrução operacional — para esses, consulte o documento
canônico do respectivo dono.

## Convenção de nomes

- Prefixo numérico de dois dígitos quando a ordem de leitura importar
- `snake_case` com iniciais maiúsculas, sem acentos e sem caracteres especiais
- Nome deve comunicar escopo e dono; nomes genéricos não são aceitos
- Versões substituídas vão para `99_Archive`; não se versiona por sufixo no nome do arquivo

## Manutenção

Este índice deve ser atualizado sempre que uma pasta for criada, renomeada ou tiver seu dono
alterado. Responsável pela manutenção: governança NAR ECO.
