# _archive

Skills descontinuadas ou substituídas pela versão canônica em `rufas-skills/` são movidas para cá — nunca apagadas. Preservadas por histórico e para permitir reverter uma decisão de arquivamento se necessário.

Vazio até a primeira auditoria real do runtime (`../runtime-audit-report.md`) identificar candidatos a arquivamento e um humano aprovar o arquivamento.
